Entry for the make.fun competition
[One-Sentence Absurd Invention Pitch](https://make.fun/competitions/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a):
one sentence (max 220 characters) pitching a ridiculous invention that fixes
a tiny everyday annoyance.

## The pitch

> A TV remote that, when lost down the sofa, inflates like a pufferfish and waddles out on tiny legs to be found.

(111 characters, one sentence, no trailing newline.)

The annoyance: the TV remote vanishes down the sofa. The invention: a
remote that inflates like a pufferfish to escape the cushions, then waddles
out on tiny legs to be found. The laugh is the invention itself — silly, yet
weirdly plausible as a fix.

## Run

```sh
node main.ts   # writes the sentence to /output/entry.txt
```

Node 22+, standard library only, no network. `main.ts` refuses to write if
the pitch is not 1–220 characters.
